## Deploy e entrega
- [ ] Executar npm run build e npm run preview.
- [ ] Publicar na Vercel ou Cloudflare.
- [ ] Configurar DNS, domínio e HTTPS (com e sem www).
- [ ] Testar links, imagens e navegação no domínio oficial.
- [ ] Executar Lighthouse no mobile e desktop.
- [ ] Enviar site ao cliente para validação e realizar ajustes finais.
